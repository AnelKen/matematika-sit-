# Matematika және қаржылық сауаттылық

Бұл сайт 5 және 6 сынып оқушыларына арналған қаржылық сауаттылықты дамыту мақсатында жасалды. Сайтта Google Form арқылы интерактивті тест тапсырмалары және қаржылық терминдердің глоссарийі ұсынылған.

## 📌 Жоба туралы

- **Жоба атауы**: Математиканы оқытуда оқушылардың қаржылық сауаттылығын дамыту
- **Автор**: Өмірбек Анель Руслановна
- **Оқу орны**: Көкшетау қаласының Шоқан Уалиханов атындағы университеті
- **Білім деңгейі**: Магистратура, 2 курс
- **Жасалған жыл**: 2025
